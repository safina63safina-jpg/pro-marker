# CLAUDE.md — Документация проекта Pro-Marker Mini App

## Структура файлов

```
tg-app/
├── index.html          ← Точка входа. Все 6 экранов прописаны здесь статически.
├── css/
│   └── app.css         ← ВСЕ стили. Цвета — только через CSS-переменные Telegram.
├── js/
│   ├── catalog.js      ← Данные каталога (имена, фото, цены, сезоны).
│   ├── cart.js         ← Корзина (localStorage). API: Cart.add/remove/setQty/clear.

└── CLAUDE.md           ← Этот файл.

../photos/              ← Фотографии товаров (на уровень выше tg-app/).
```

## Навигация между экранами

Все экраны существуют в DOM одновременно. Видимость управляется через CSS `transform: translateX(...)`.

```
screen-home
  → navigate('catalog') → screen-catalog (вкладки: highlighters / stickers)
      → navigate('product') → screen-product (карточка товара)
  → navigate('cart')    → screen-cart
      → navigate('checkout') → screen-checkout (2 шага)
          → navigate('success') → screen-success
              → goHome() → screen-home (корзина очищается)
```

**Функции навигации (в app.js):**
- `App.navigate(screenId, data)` — переход вперёд (анимация слева направо)
- `App.goBack()` — возврат назад (анимация справа налево)
- `App.goHome()` — сброс в начало после успешного заказа

## Где менять данные каталога

Всё в файле **js/catalog.js**:

### Цены
```js
CATALOG.highlighters.price = 690;  // изменить цену текстовыделителей
CATALOG.stickers.price     = 470;  // изменить цену стикеров
```

### Названия и фото товаров
```js
CATALOG.highlighters.regular = [
  { id: 'h-r-1', name: 'Пастельный рассвет', image: '../photos/IMG_8384.PNG' },
  // Добавить или изменить строку здесь
];
```

### Сезонные наборы (привязка к сезону)
```js
CATALOG.highlighters.seasonal.summer = [
  { id: 'h-s-su1', name: 'Летний бриз', image: '../photos/IMG_8391.PNG' },
  { id: 'h-s-su2', name: 'Тропический закат', image: '../photos/IMG_8392.PNG' },
];
```

Сезон определяется автоматически по дате устройства в функции `getCurrentSeason()`.

## Telegram WebApp API — что и где используется

| Элемент | Где в коде | Назначение |
|---------|-----------|-----------|
| `tg.ready()` | app.js, старт | Убирает мигание белого экрана |
| `tg.expand()` | app.js, старт | Разворачивает на весь экран |
| `tg.themeParams` | `_applyTheme()` | Применяет цвета Telegram (день/ночь) |
| `tg.MainButton` | `_setMain()` | Основная кнопка действия |
| `tg.BackButton` | `_setBack()` | Кнопка «Назад» |
| `tg.HapticFeedback` | объект `Haptic` | Тактильный отклик |
| `tg.initDataUnsafe.user` | `_prepHome()`, `_initCheckout()` | Имя пользователя |

## Сезонная логика

Функция `getCurrentSeason()` в catalog.js определяет сезон по месяцу:
- **Весна**: март–май (3–5)
- **Лето**: июнь–август (6–8)
- **Осень**: сентябрь–ноябрь (9–11)
- **Зима**: декабрь–февраль (12, 1, 2)

В каталоге всегда показываются:
- 2 сезонных набора текущего сезона (активные)
- 6 обычных наборов (всегда активные)
- 6 сезонных наборов других сезонов (заблокированы, затемнены)

## Настройка уведомлений о заказах (config.js)

Файл `js/config.js` — единственное место, куда нужно вставить секретные данные.

### Как получить BOT_TOKEN
1. Открой `@BotFather` в Telegram
2. Напиши `/newbot`
3. Придумай имя и username бота
4. Скопируй токен вида `7891234567:AAFxxx...`

### Как получить OWNER_CHAT_ID
1. Открой `@userinfobot` в Telegram
2. Напиши `/start`
3. Скопируй числовой ID, например `123456789`

### Заполнить config.js
```js
const CONFIG = {
  BOT_TOKEN:     '7891234567:AAFxxx...',
  OWNER_CHAT_ID: '123456789',
};
```

После оформления заказа бот пришлёт тебе сообщение:
```
🛒 Новый заказ #4721
━━━━━━━━━━━━━━━━━━
  • Летний бриз × 2 = 1 380 ₽
━━━━━━━━━━━━━━━━━━
💰 Итого: 1 380 ₽

👤 Получатель: Анна Петрова (@username)
📍 Адрес: Москва, ул. Примерная, д. 1, кв. 5
📞 Телефон: +79991234567
```

**Важно:** Не публикуй `config.js` на GitHub — там секретный токен.

## Как протестировать локально

1. Открыть `tg-app/index.html` напрямую в браузере — все экраны работают.
2. Telegram WebApp API будет недоступен (нет SDK), но app.js обрабатывает `tg = null` без ошибок.
3. Для реального тестирования:
   - Выложить папку `tg-app/` + `photos/` на хостинг с HTTPS
   - Создать бота через `@BotFather`
   - Прописать URL в `@BotFather` → Bot Settings → Menu Button / Web App URL
