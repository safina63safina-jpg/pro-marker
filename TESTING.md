# TESTING.md — Руководство по тестированию Pro-Marker Mini App

Перед тобой — Telegram Mini App для продажи текстовыделителей и стикеров-закладок.  
Это руководство охватывает всё: запуск, полный сценарий покупки и все граничные случаи.

## 2. Запуск локально

**Требования:** любой веб-сервер с HTTPS (или localhost). Телеграм SDK в браузере без Telegram не работает — приложение это учитывает и корректно падает на `tg = null`.

### Вариант А — открыть файл напрямую (без сервера)

1. Открой `tg-app/index.html` в браузере.  
2. Все экраны, навигация и корзина работают.  
3. Telegram-специфичные функции (haptic, MainButton, имя пользователя) недоступны — это ожидаемо.

### Вариант Б — live-сервер (VS Code)

1. Установи расширение «Live Server».  
2. Правой кнопкой на `tg-app/index.html` → «Open with Live Server».  
3. Открывай в браузере с DevTools → мобильный эмулятор (iPhone 12, 390×844).

### Вариант В — деплой (уже запущен)

Живая версия: **https://tg-app-flame.vercel.app**  
Telegram-бот: **@highliter_rus_bot**  
Для теста в Telegram открой бота и нажми кнопку «Магазин».

## 3. localStorage — ключи и сброс

Приложение хранит состояние в `localStorage` браузера. Перед тестированием нужно знать, что сбрасывать.

| Ключ | Что хранит | Эффект при удалении |
|------|-----------|-------------------|
| `pm_onboarded` | Факт прохождения онбординга | Покажет онбординг заново |
| `pm_offer_seen` | Факт просмотра оффер-модала | Покажет оффер-модал заново |
| `pm_gift` | Прогресс программы лояльности (число наборов сверх базовых 2) | Сбросит до 2 / 10 |
| `pro_marker_cart_v1` | Содержимое корзины (JSON) | Очистит корзину |

**Как сбросить всё состояние:**
```js
// Вставить в DevTools → Console
localStorage.removeItem('pm_onboarded');
localStorage.removeItem('pm_offer_seen');
localStorage.removeItem('pm_gift');
localStorage.removeItem('pro_marker_cart_v1');
location.reload();
```

**Как симулировать возвращающегося пользователя:**
```js
localStorage.setItem('pm_onboarded', '1');
localStorage.setItem('pm_offer_seen', '1');
location.reload();
```

## 5. Чек-лист тестирования

### 5.1 Онбординг (первый запуск)

**Подготовка:** удали `pm_onboarded` из localStorage, перезагрузи.

- [ ] При загрузке показывается экран онбординга, нижняя навигация скрыта
- [ ] Три блока функций отображаются: «Текстовыделители», «Стикеры-закладки», «Программа лояльности»
- [ ] Кнопка «Начать» занимает всю ширину, высота ≥ 44px
- [ ] Нажатие «Начать» анимированно переходит на экран каталога
- [ ] После «Начать» появляется оффер-модал (если `pm_offer_seen` не установлен)
- [ ] После «Начать» ключ `pm_onboarded = '1'` сохранён в localStorage
- [ ] При повторной загрузке (c `pm_onboarded`) онбординг не мигает — сразу виден каталог

**В Telegram:** приветствие должно включать имя пользователя — «Привет, [Имя]! 👋». Без Telegram — «Привет! 👋».

### 5.2 Оффер-модал

**Подготовка:** удали `pm_offer_seen`, `pm_onboarded`, перезагрузи.

- [ ] После нажатия «Начать» модал появляется с плавной анимацией
- [ ] Содержимое: emoji 🎁, заголовок «Ежедневник в подарок!», три пункта списка

- [ ] При повторной загрузке (с `pm_offer_seen`) модал не появляется

### 5.3 Каталог

**Текущий сезон (июнь = лето):** активны летние наборы.

- [ ] Заголовок «Текстовыделители» или «Стикеры-закладки» соответствует активной вкладке
- [ ] Секция «Сезонная коллекция · лето» — 2 карточки (не заблокированы)
- [ ] Секция «Классика» — 6 карточек (всегда активны)

- [ ] Первые 6 карточек появляются с stagger-анимацией при загрузке

**Переключение категорий (нижняя навигация):**

**Заблокированные карточки:**

## 6. Навигация и анимации

### Переходы между экранами
- **Вперёд:** текущий экран уходит влево (-28%), новый приезжает справа → центр. Длительность: 270ms.
- **Назад:** текущий уезжает вправо (100%), предыдущий выезжает из -28% → центр.

Проверить:
- [ ] Нет «прыжков» экрана при переходе назад
- [ ] После перехода назад у «убранного» экрана нет лишних inline-стилей

### FAB корзины
- [ ] Виден на всех экранах, кроме корзины, оформления и успеха
- [ ] Счётчик обновляется моментально при добавлении/удалении из корзины

### Нижняя навигация
- [ ] Скрыта на экранах: успех, онбординг
- [ ] Активный пункт подсвечен: «Маркеры» / «Стикеры» на каталоге и товаре; «Корзина» на оформлении; «Подарок» на экране подарка

## 7. Сезонная логика

Сезоны определяются по месяцу устройства (функция `getCurrentSeason()` в `catalog.js`):

| Месяцы | Сезон | CSS-класс | Эмодзи |
|--------|-------|-----------|-------|
| 3–5 | весна | `spring` | 🌸 |
| 6–8 | лето | `summer` | ☀️ |
| 9–11 | осень | `autumn` | 🍂 |
| 12, 1, 2 | зима | `winter` | ❄️ |

**Как проверить другой сезон:**
```js
// DevTools → Console — переопределить дату
const origDate = Date;
window.Date = class extends origDate {
  constructor(...args) { super(...args); }
  getMonth() { return 10; } // 10 = ноябрь (осень)
};
location.reload();
```

Ожидаемый результат после reload с ноябрём:
- [ ] Баннер на главной «Осенняя коллекция 🍂»
- [ ] В каталоге активны осенние наборы (Золотая осень, Янтарный дождь / Кленовый листопад, Тыквенный уют)
- [ ] Летние наборы заблокированы, toast «Набор появится летом 🔒»

## 8. Тема (светлая/тёмная)

CSS-переменные Telegram применяются через `_applyTheme()` в `app.js`. Вне Telegram используются fallback-значения:

| Переменная | Fallback |
|-----------|---------|
| `--bg` | `#f0f2f5` |
| `--bg2` | `#e5e8ee` |
| `--text` | `#1a1a1a` |
| `--hint` | `#909090` |
| `--accent` | `#2AABEE` |

- [ ] В светлой теме: фон светло-серый, текст тёмный, акцент синий
- [ ] В тёмной теме Telegram: фон тёмный, текст светлый (без хардкод-цветов)
- [ ] Переключение темы в Telegram на лету меняет цвета (событие `themeChanged`)

## 13. Что НЕ тестируется (намеренно)

- **Оплата** — не реализована; заказ считается принятым сразу после ввода данных.
- **Реальная база данных** — заказы не сохраняются на сервере, только логируются в консоль (или отправляются боту).
- **Автентификация** — Mini App не проверяет подпись `initData` на сервере.

## 14. Типичные проблемы и их решение

| Проблема | Причина | Решение |
|---------|---------|---------|
| Белый экран при открытии | `config.js` не найден | Убедись, что файл существует в `tg-app/js/` |
| Фото не загружаются | Неправильный путь или отсутствующий файл | Проверь `tg-app/photos/`, имена файлов чувствительны к регистру |
| Онбординг не показывается | `pm_onboarded` уже в localStorage | Удали ключ через DevTools → Application → Local Storage |
| Оффер-модал не появляется | `pm_offer_seen` уже установлен | Удали ключ |
| Уведомление боту не приходит | `CONFIG.BOT_TOKEN` содержит `ВСТАВЬ_ТОКЕН_ЗДЕСЬ` | Обычная ситуация в dev-окружении, заказ всё равно оформляется |
| Сезон не тот | Дата устройства | Используй трюк с переопределением `Date` из раздела 7 |
